# 依頼書：2R得点表示の3D化（造形担当向け）

作成: 2026-11-27 ／ 依頼元: 統括（クイズ大会スコアボード）
リポジトリ: https://github.com/Nienu1976/numazu-quiz-scoreboard （Public）

## 1. 背景
クイズ大会「沼東OB例会1st」（静岡県沼津市・沼津東高校OB）の得点表示システムを作っている。
2R（連答つき5○2×）の表示画面の2Dモックが固まったので、**これを3Dレンダリングで立体的に見せたい**。

- 2Dモック（基準デザイン）: `docs/numazu_ob_quiz_scoreboard/mock/2r_mock.html`
  （公開版: https://claude.ai/artifact/P9dgFpwMEKwHgTa4uQqszK ※閲覧には依頼者のアカウントが必要。リポジトリのHTMLを直接開けば同じものが動く）
- 要件定義: `docs/numazu_ob_quiz_scoreboard/requirements.md`
- デザイン決定事項と失敗例: `docs/numazu_ob_quiz_scoreboard/design_system.md` ← **必読**

## 2. お願いしたいこと
2Dモックのデザインと動きをそのまま3D化した、動く試作（HTML 1枚＋必要なアセット）。

### 立体にするもの
| 要素 | 3D化のイメージ |
|---|---|
| 参加者の札（12枚） | 厚みのある木札/金属札として並べる。カメラはわずかに見下ろす角度 |
| 札の内容（S2） | 席番号・名前・卒業期・○の数・×枠。**名前が最も大きく、常に正面から読めること** |
| 連答権の信号灯 | 札の上の回転灯。連答権を持つ間ずっと回転し発光し続ける。消失で停止 |
| ○の増加 | 数字の札がパタッとめくれる（回転） |
| 連答 +2 | 「連答 +2」が大きく飛び出す |
| 勝ち抜け | 自席のまま、下部の黒板が赤に裏返って「1抜け」等。赤帯「1抜け 名前」が横切る。**名前は隠さない** |
| 失格 | 札が裏返り錆色に |
| 組の終了 | 6人勝ち抜けで「第1組 終了」 |

### 操作部分
2Dモック下部の操作ストリップ（1行目=参加者 / 2行目=○ / 3行目=×、1手戻す、スルー）はそのまま2Dで残し、押すと3D表示が動くこと。ゲームロジックは2Dモックのものを流用してよい。

## 3. 守ってほしい制約（重要）
1. **見た目のモチーフは沼津港**（競り札・魚箱の文字・港の番号標識・黒板／駿河湾の藍・船体の赤白・錆・ロープの生成り）。ただし**言葉と演出の意味はクイズとして正しく**。「落札」「競り」等の市場用語は禁止（過去に失敗済み）
2. **楕円・グラデーション・ありがちなフォント禁止**（「AI作成っぽさ」の排除）。3Dの陰影がグラデーションに見えないよう、**フラット／トゥーン寄りのシェーディング**を推奨。発光（信号灯）だけはグロー可
3. **主役はプレイヤー**。演出が名前を隠す・読みにくくすることは不可
4. **余計な情報を足さない**（問題数、勝ち抜け者の一覧レールなどは不要と判断済み）
5. **オフライン動作**: ライブラリ・フォント・モデルはすべて同梱（CDN不可）。Three.js 推奨
6. **本番は性能不明のWindows PC**（Chrome/Edge）、プロジェクター 16:9 基準。1080pで安定60fpsを目標。重い効果を切る**軽量モード**を必ず用意
7. テクスチャ・モデルは自作またはライセンスが明確なもののみ
