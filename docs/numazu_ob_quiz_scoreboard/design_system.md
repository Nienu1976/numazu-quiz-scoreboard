# デザインシステム（作業中）

担当: harbor-designer / 最終更新: 2026-11-27

## 決定事項
- **ラウンドごとに専用の画面デザインを作る。** 全ラウンド共通の汎用札に情報を詰めない。各画面は、そのラウンドのルールの核（2Rなら 5○2× と連答権）が一目でわかることを主役にする。
- 沼津港モチーフは手段であって目的ではない。モチーフで飾るより、ルールが伝わることを優先する。
- モチーフは**見た目（色・形・書体・質感）だけ**に使う。表示する言葉と演出の意味はクイズとして正しくする（「落札」「競り開始」など競りの用語は使わない）。
- 2Rのベースは v1 の競り札ビジュアル（ユーザー評価「デザイン的には一番よかった。余計な情報が多いだけ」）。札の情報量は比較案 S1〜S3（mock/2r_slim_compare.html）から選ぶ（選択待ち）。

## 2R 次版で入れること（ユーザー指摘・統括経由）
- 連答権の信号灯は、連答権を持っている間ずっと回転・発光し続ける（1回点滅で終わりは不可）。発光の表現としての blur/drop-shadow のグローは可。面の塗りのグラデーションは引き続き禁止。連答権が消えたら止まる
- 勝ち抜けの表示でプレイヤー名を隠さない。主役はプレイヤー。「1抜け」などは名前の邪魔にならない位置と形で出す
- 上部の勝ち抜けレールは削除し、札が飛ぶ演出もなくす。勝ち抜けた人は自分の席のまま勝ち抜け状態で表示する
- 問題番号（Q番号）は表示しない
- 用語はクイズ用語にする（第2ラウンド 連答つき5○2× / 第◯組 / 勝ち抜け / 1抜け / 失格 / 連答権 / 連答 +2）。ルールは画面に簡潔に表示する。連答で+2になったことを観客にわかるように出す。6人勝ち抜けたら「第◯組 終了」を表示する
- 暫定ルール: 連答で2○を取ったあと連答権は続かない／スルーでは連答権を保つ／5○を超えても表示は5○で止めて勝ち抜け

## 失敗した試み
### 2Rモック v1（mock/2r_mock.html, 2026-11-27）→ ユーザー評価「ダサい」
- 競り札・値札・信号灯・「落札」・海面に沈む演出などを1枚の札に全部載せた
- 問題点（ユーザー指摘）:
  1. 2R固有のルール（連答つき5○2×）の画面に見えず、全ラウンドの要素を一緒くたにしたように見える。「落札」は他ラウンド（3R）と紛らわしい
  2. 手抜きに見える
  3. 情報の詰め込み（席番・プレート・期・値札・メーター・×枠・灯を1枚に）
  4. 色と書体のセンス（4色ベタ塗り＋Dela Gothic One の組み合わせが野暮ったい）
  5. コンパネが素っ気ない（赤と紺の箱が並ぶだけ）
- 教訓: 世界観の小道具を足すほど安っぽくなる。ラウンドのルールから画面を設計する
