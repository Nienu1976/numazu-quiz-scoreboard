# 参考：ペーパー結果のターンオーバー発表（過去大会 SNStheAnother の実装から抽出）

抽出: 2026-11-27 統括。出典はユーザーが過去に作った大会システム（Firebase公開版の表示画面JS）。個人情報は含まない。

## 過去大会での流れ
- **上位から発表**する（1位が最初）。発表は「バッチ（まとまり）」単位で、操作担当が1クリックずつ段階を進める
- 各バッチは 3段階: ①カットイン（そのバッチの意味を示す帯。任意） → ②**順位だけ**の札を表示（名前は伏せた表面） → ③札が**裏返って（ターンオーバー）名前が出る**
- 過去大会のバッチ構成（48人・色4段階）:

| 段階 | 対象 | 札の色 | カットイン |
|---|---|---|---|
| 1-2 | 1位（単独・横長の大きい札） | 金 | なし |
| 3-5 | 2〜4位 | 赤 | THE TOP 4 / ADVANTAGE 3pts |
| 6-8 | 5〜8位 | 青 | IN THE BLUE / ADVANTAGE 2pts |
| 9-10 | 9〜12位 | 青 | なし |
| 11-13 | 13〜24位 | 緑 | ROUND 1-2 ENTRIES |
| 14-15 | 25〜36位 | 緑 | なし |
| 16-17 | 37〜48位 | 緑 | なし |

## 動き
- 札の登場: 奥から手前へ、横向き(rotateY 90°)から正面へ回り込みながら拡大。1枚ずつ0.1秒ずらして順に出る（スプリング）
- ターンオーバー: 札が Y軸で180°回転（スプリング、やや弾む）。表=順位と色、裏=順位・名前・色
- 1位だけ横長の特大札
- フラッシュ（白い閃光が横切る）で場面転換
